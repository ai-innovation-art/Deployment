    GitHub Codespaces Setup

    Docker is pre-installed in every Codespace — no setup needed. Open the repo, click Code → Open with Codespaces, and every lab command works in the integrated terminal.

    A few things to know: files persist between Codespace sessions (the filesystem is not reset unless you rebuild the container); Docker images reset on a full rebuild (keep your Dockerfiles in the repo so you can re-pull or rebuild instantly); and forwarded ports are available in the browser so you can reach your containers without extra tooling.

    The Running Project Codebase: labs/reliability-api

    All labs run against a real, fully-implemented application located directly in this repo at labs/reliability-api/. It contains app/main.py (FastAPI), unit tests (tests/test_main.py), multi-stage and naive Dockerfiles, and compose.yaml. You can build, test, break, and inspect it locally in real time.

    Lab structure

    Each lab page follows the same pattern:

    🔧 Environment setup

    Verify the tools you need are available and at the right version.

    📋 Command reference

    Every important command with all flags — annotated with comments, showing real output.

    🧪 Experiments

    Guided experiments to build intuition — including deliberate failure scenarios.

    ⚠️ Failure cases

    Common mistakes, the error messages they produce, and how to fix them.
