    Chapter 01 · Deploy and trace

    NamespaceLogical folder: names, permissions, quotas. Not network isolation.

    ConfigMapPlain settings, values are strings. Change ≠ pod restart.

    SecretstringData plain → stored base64. Encoding, not encryption. Types: generic, tls, docker-registry.

    Labels and selectors5 places: tags on objects (A, C), searches (B, D), badge on pods (E). D≠E rejected, B≠E silent.

    Labels vs annotationsSearch by it → label. Information → annotation.

    Service typesClusterIP · headless (None) · NodePort · LoadBalancer. Needed only if something connects in.

    port / targetPort / nodePortService port · container port (can be a name) · port on every node (30000–32767).

    StatefulSetFixed name + own disk, ordered start. Not a fixed IP. Needs headless Service + serviceName.

    DeploymentRandom names via ReplicaSet. Stateless apps.

    StoragePVC (request) → PV (disk) ← StorageClass. RWO/ROX/RWX/RWOP. PVC survives pod delete.

    envvalue · configMapKeyRef · secretKeyRef · fieldRef (Downward API).

    Downward APIPod facts (node, IP, name) passed into the container.

    ProbesReadiness = traffic, liveness = restart, startup = slow start. Liveness never checks dependencies.

    ResourcesRequests = scheduler, limits = runtime cap. Memory over → OOMKilled. QoS: Guaranteed / Burstable / BestEffort.

    Taints and tolerationsNoSchedule / PreferNoSchedule / NoExecute. Control plane tainted. Toleration = pass, not invitation.

    Init containersRun first, must exit 0, run on every pod start → idempotent.

    command / args= Docker ENTRYPOINT / CMD.

    Job and CronJobRun to completion. Cron + timeZone, concurrencyPolicy, backoffLimit, ttl. restartPolicy Never / OnFailure.

    Kustomizeapply -k applies all listed files. Safe to repeat.

    DefaultsFields you don't write get defaults; see them with -o yaml.

    Request traceHost port → nodePort → iptables (KUBE-SVC → KUBE-SEP → DNAT) → pod. No proxy in the path.

    iptables load balancingRandom probability rules: 3 pods = 0.333 → 0.5 → rest.

    DNSCoreDNS 10.96.0.10, search list makes short names work. Normal → ClusterIP, headless → pod IP.

    IP ranges10.96.x.x Services · 10.244.N.x pods (one range per node).

    DebuggingThrowaway curl pod inside the cluster. Pod status → cause table. kubectl wait.

    Self-healingContainer fails → kubelet restarts in same pod. Pod gone → ReplicaSet makes a new one. Bad release → rollback.

    Chapter 02 · Rollouts

    Deployment → ReplicaSet → Podpod-template-hash = template fingerprint. Deployment only scales ReplicaSets.

    What triggers a rolloutChange inside template → new RS. Outside (replicas, strategy) → in place. Old template → old RS reused.

    Rolling update mathsmax = replicas + maxSurge, min = replicas − maxUnavailable. Surge rounds up, unavailable down.

    minReadySecondsReady for N s before counted available. Slows rollouts.

    Ship a releaseset image + change-cause. Old and new serve together briefly → keep compatible.

    Broken releaseMissing image → ImagePullBackOff. Broken app → Running 0/1. Both: users safe with maxUnavailable 0.

    EndpointSlice ready flagNot-Ready pods listed with ready=false, get no traffic.

    progressDeadlineSeconds600 s → ProgressDeadlineExceeded. Never auto-rollback.

    Rollbackundo reuses old RS, near-instant. Revision renumbered.

    Undo trapSecond undo returns to the broken one. Use --to-revision=N.

    Revision history--revision=N, diff two revisions. change-cause can lie → git is the real history.

    Pause / resumeStack changes → one RS, one rollout. undo refused while paused.

    RecreateKill all, then start all. Downtime. Use when old and new can't coexist.

    Immutable fieldsSelector, clusterIP → delete and recreate.

    Industry standardYAML in git → PR → CI/CD or GitOps. Rollback = git revert. Immutable tags, never :latest.

    revisionHistoryLimitOld RS = few KB, no pods. Keep 3–10, never 0.

    Recreate downtimeAll pods stop together (Completed = clean SIGTERM exit), new ones start together. Seen as empty responses.

    rollout restartrestartedAt annotation in template → new RS, zero downtime. Use after ConfigMap/Secret change.

    DriftLive edits are overwritten by the next apply. apply manages only fields in the file.
