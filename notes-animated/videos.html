How these were made

The videos are rendered with Manim Community, the open-source, MIT-licensed animation engine created for math explainers. Every scene is plain Python in video-src/, and common.py holds the shared visual style. To re-render one at 720p:

cd video-src
manim -qm m03_kubectl_apply.py M03KubectlApply

The diagrams inside each module are animated in the browser by assets/anim.js. It uses the browser's built-in Web Animations API, with no third-party code. A diagram builds itself the first time it scrolls into view, then shows data flowing along its arrows. Use ▶ Replay build and ⏸ Pause flow under each diagram to control it.
